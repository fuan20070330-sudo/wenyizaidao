# 纹以载道

中华传统纹样的数字解码与再创作。2026 年第十四届全国大学生数字媒体科技作品及创意竞赛参赛作品原型。

## 在线访问

https://fuan20070330-sudo.github.io/wenyizaidao/

## 作品定位

《纹以载道》是一款响应式 Web 应用，把中华传统纹样拆解为“母题 + 结构 + 构成”的视觉语法。用户可以在纹样库中识纹、在解码任务中理解寓意，并在纹样实验室中完成配色、构成与再创作，最终导出 PNG 作品。

- 参赛分类：自主命题 - 移动与网络应用开发
- 作品形态：响应式 Web 应用 / 可离线单文件 Demo
- 运行条件：普通电脑或手机浏览器，无需专用硬件、无需登录
- 当前版本：v0.4 内容与搜索增强版（200 个纹样）

## 如何打开

### 方式一：直接打开

双击 `index.html`，或在浏览器中打开该文件，即可运行。

### 方式二：本地服务器

在本目录执行：

```powershell
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

### 方式三：单文件离线版

直接打开 `纹以载道_离线版.html`。该文件已将 CSS、纹样数据和交互逻辑全部内嵌，适合在没有网络或没有本地服务器时演示。

## 已实现功能

1. 纹样库：10 个分类、200 个传统纹样，每个纹样都有独立摘要、描述、标签与馆藏参照。
2. 搜索与筛选：支持中文、拼音、多关键词、标签、寓意、年代、构成方式和藏品编号搜索；点击标签显示“已选中”，无结果时推荐相近标签。
3. 排序与重置：支持常见度、精确实物、名称拼音和分类排序，并提供“清除全部筛选”。
4. 实物对照：悬停或键盘聚焦纹样卡片时显示馆藏实物或同类馆藏参照；详情弹窗展示藏品编号、年代、馆藏机构与来源链接。
5. 解码任务：5 道互动题，包含即时反馈与完成结果。
6. 纹样实验室：母题、配色、构成方式、密度和尺度实时生成。
7. 作品导出：Canvas 导出 1800 × 1440 PNG，自动附上作品标题、构图方式、配色和馆藏来源。
8. 本地收藏：使用 localStorage 保存最多 6 个纹样方案。
9. 响应式布局：桌面端与移动端自适应。
10. 离线能力：无需外部字体、CDN 或 AI API；单文件版内嵌馆藏实物图像。
11. 卡片懒加载：纹样图形在进入视口附近时才渲染，降低首屏压力。
12. 无障碍基础：键盘操作、ARIA 标签、减少动效偏好。
